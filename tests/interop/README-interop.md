# 업스트림 상호운용 오라클

이 테스트는 키트를 설치한 홈에서 진짜 agent-switchboard 코드가 `serve` 시작 때 하는 일(`setup.refresh_hierarchy(silent=True)`, 곧 `hierarchy_install.refresh`)을 그대로 두 번(Codex 롤이 있을 때) 그리고 한 번 더(Codex CLI 가 없을 때) 실행해, CLAUDE.md / AGENTS.md / GEMINI.md 와 네 롤 파일(Explore.md, economy-worker.md, explorer.toml, worker.toml)이 바이트 단위로 그대로이고 각 작성기가 "left untouched" 나 "unchanged" 류의 결과를 돌려주는지, 그리고 `update_hooks` 가 settings.json 에 자기 훅을 다시 넣은 뒤에도 키트의 SessionStart 훅(sync-roles.ps1)이 정확히 한 번, 바뀌지 않고 남아 있는지를 증명합니다. 시나리오는 셋입니다: 업스트림이 이미 설치된 홈(fixture), 세 호스트 폴더만 있는 빈 홈(fresh), `.claude` 만 있는 홈(claude-only). 모든 쓰기는 `%TEMP%` 아래 가짜 홈에서만 일어나고, install.ps1 은 항상 `-SkipEnvVar` 로 돌며, 오라클은 가짜 홈 밖으로 가는 업스트림 쓰기를 막고 실제 프로필과 사용자 환경 변수가 그대로인지도 확인합니다.

실행하려면 업스트림을 이 저장소 밖에 직접 받아 원하는 태그를 꺼낸 뒤(`git clone <agent-switchboard 저장소> C:\src\asb` 다음 `git -C C:\src\asb worktree add C:\src\asb-v1.0.47 v1.0.47`), `powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\interop\run-interop.ps1 -UpstreamDir C:\src\asb-v1.0.47` 처럼 실행합니다(필요하면 `-Python`, `-KeepTemp`). Python 3.11 이상이 필요하고, 종료 코드 0 이면 모두 통과입니다. 업스트림 코드는 PolyForm-Noncommercial 라이선스이므로 이 저장소에는 한 줄도 복사하지 않으며, 오라클(`upstream_interop.py <upstream_src_dir> <fake_home>`)은 명령줄로 받은 폴더에서 import 만 합니다. 업스트림 체크아웃을 이 저장소 안에 두면 두 스크립트 모두 실행을 거부합니다.
